# Frameworks and Standards for Web Security

As many security analyst and security researchers or attackers uses of structured approaches, methods of the exploitation according to the certain frameworks to build, test and maintain secure web application. It makes easier to find the vulnerabilities and reduces the time for finding it.

**The professional frameworks that are used are listed below**:
- [NIST Cybersecurity Framework (CSF) 2.0](https://www.nist.gov/cyberframework): It is mostly used to roadmap for managing risk, organized into six core functions: Identify, Protect, Detect, Respond, Recover, and Govern.
- [ISO/IEC 27001 & 27002](https://www.iso.org/standard/27701): The primary international standard for validating information security management systems (ISMS) through formal certification.
- [CIS Critical Security Controls](https://www.cisecurity.org/controls): A prioritized set of actions designed to stop the most common and dangerous cyber attacks.
- OWASP (Open Web Application Security Project): which is an community built for web application security. More interesting one is [OWASP Web Security Testing Guide (WSTG)](https://owasp.org/www-project-web-security-testing-guide/stable/) which is an technical framework specifically for penetration testers and developers to test the security of web applications.
- SOC 2 Framework: Focused on managing customer data based on five `trust service principles`: security, availability, processing integrity, confidentiality, and privacy
